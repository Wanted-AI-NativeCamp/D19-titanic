data/titanic.csv의 결측치를 찾는 t2_missing.py 파일을 만들고 실행해줘
- 칸 마다 결측 개수와 비율을 표로, 결측이 많은 순서로
- 결측이 있는 칸 마다 비어있는 행 3개씩 보여줘
아직 아무것도 고치거나 채우지마,
결측을 찾는 코드가 한줄씩 무슨 뜻인지 설명해줘

Fare가 0인 승객만 골라서, 이름, 객실 등급, 티켓 번호, 나이, 생존여부를 보여줘
몇 명인지, 그리고 이 0이 "공짜 표" 인지 "기록이 없는 것"인지 판단하려면 무엇을 더 확인해야하니?
니 생각을 말할땐 데이터에서 확인한 것과 추측을 나눠서 말해줘

결측이 있는 칸(Age, Cabin, Embarked) 마다 "왜 비었을까" 데이터로 확인해줘
- Age: 나이가 빈 사람과 아닌 사람의 생존율 비교
- Cabin: 객실등급(pclass)별로 cabin이 비어있는 비율
- Embarked: 비어있는 티켓번호와 객실, 같은 티켓을 가진 사람이 있는지 결과를 보고 각 칸이 4가지 유형(우연/다른 칸과 관련/값 자체가 이유/원래 없음) 중 어디에 가까운지 근거와 함께 제안해줘, 결정은 내가 할게.

Age, Cabin, Embarked의 결측치 처리 방법을 칸마다 2가지씩 제안해줘
방법마다 장점, 단점, 처리 후 남는 행수를 표로 보여줘
아직 코드는 만들지 마
Age는 이름(name)에 들어있는 호칭(mr, mrs, miss, master)을 쓰는 방법도 꼭 넣어줘

내가 고른 처리 방법이야
이대로 정제하는 파일 t3_clean.py 만들어줘
- age: 호칭별 중앙값(A) (그리고 원래 비어있었는지 age_missing 칸으로 남겨줘)
- Cabin: 있음/없음 칸으로 변환 (원본 Cabin은 유지하고 has_cabin 칸으로 남겨줘)
- Embarked: S로 채우기
정제한 결과는 data/titanic_clean.csv로 저장하고 정제 전후의 행수와 칸별 결측 개수를 나란히 보여줘.
저장전에 코드를 보여주고 한줄씩 설명해줘

나이대별 생존율을 결측 처리 방법 4가지로 비교하는 t4_experiment.py를 만들고 실행해줘
나이대: 어린이(0~12), 10대(13~19), 청년(20~39), 중년(40~59), 노년(60+)
처리 방법: 
1. 나이 빈 행 지우기
2. 전체 중앙 값으로 채우기
3. 호칭별 중앙 값으로 채우기
4. 0으로 채우기
나이대마다 생존율과 인원 수를 방법별로 나란히 표로 보여줘
가장 크게 달라진 칸이 어디이고 왜 그런지 설명해줘

data/titanic_clean.csv 로 t5_groupby.py 를 만들고 실행해줘
- 성별 생존율과 인원수
- 객실 등급별 생존율과 인원수
- 성별과 * 등급 생존율 표
- 탑승 항구별 생존율과 인원수,
그리고 항구 * 등급 생존율과 인원수
비율 옆에는 항상 인원수 같이 보여줘

차트 규칙
1. 제목 = 결론 문장
2. 비율 막대에는 인원(분모)을 같이 표시
3. 막대 차트의 세로축은 0
4. 색은 뜻이 있을때만
5. 축 이름은 한글로, 단위(%, 원, 명)를 붙여서


data/titanic_clean.csv 로 plotly 차트 4개를 그리는 t6_charts.py를 만들어줘, 차트마다 chart 폴더에 html로 저장해줘

5. 축 이름은 한글로, 비율은 %로 보여줘
