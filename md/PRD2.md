# PRD2 — TITANIC Ocean Archive

- Version: 2.1 (분석 방법 단계를 실습 8단계로 수정)
- Type: 기존 프로젝트 UI 리디자인
- Design Reference: `design-simple.md`

## 1. 프로젝트 개요

1912년 타이타닉 승객 데이터의 실습 분석 결과를 현대적인 디지털 아카이브로 제공하는 웹사이트.

**목표**
- 기존 분석 데이터, 코드 및 결과 유지
- 랜딩에서 프로젝트 스토리텔링 제공
- 상세 페이지에서 분석 과정과 결과를 쉽게 탐색
- 새로운 Simple Museum Editorial 디자인 적용

## 2. 사이트 구조

```text
Landing
├── F1 Hero
├── F2 프로젝트 소개
├── F3 분석 방법 소개
├── F4 종합 분석 프리뷰
└── F5 Footer

상세 페이지
├── 프로젝트 소개
├── 분석 방법 소개
└── 종합 분석
```

랜딩은 세로 스크롤 방식이며, 각 섹션에서 해당 상세 페이지로 이동한다.

## 3. 페이지별 요구사항

| 페이지 | 주요 콘텐츠 및 기능 |
|---|---|
| F1 Hero | 타이틀, 선박 이미지, 프로젝트 소개, CTA |
| F2 프로젝트 소개 | 역사적 배경, 분석 목적 요약, 상세 이동 |
| F3 분석 방법 | 실습 8단계 요약, 상세 이동 |
| F4 종합 분석 | 기존 KPI 및 대표 차트 프리뷰, 상세 이동 |
| F5 Footer | 데이터 출처, 사용 기술, 프로젝트 정보 |
| 프로젝트 소개 상세 | 배경, 목적, 데이터셋 소개 |
| 분석 방법 상세 | 실습 8단계 태그 선택 및 실제 실습 내용 표시 |
| 종합 분석 상세 | 분석 항목별 태그 선택 및 기존 분석 결과 표시 |

## 4. 분석 방법 소개

상단 태그를 선택하면 해당 단계의 콘텐츠만 전환한다. 태그는 **실제로 실습한 8단계**를 그대로 쓴다.

- 01 데이터 살펴보기 (`t1_look.py`)
- 02 결측치 찾기 (`t2_missing.py`)
- 03 왜 비었을까 (`t2` 이후 데이터로 확인한 내용, 대응하는 스크립트 없음)
- 04 결측 처리 (`t3_clean.py`)
- 05 처리 방법 실험 (`t4_experiment.py`)
- 06 그룹별 생존율 (`t5_groupby.py`)
- 07 시각화 (`t6_charts.py`)
- 08 대시보드 (`t7_dashboard.py`)

각 단계에는 실제 수행한 분석 목적, 과정, 코드, 결과 및 해석을 표시한다.

- 실습하지 않은 `인사이트 도출` 단계는 두지 않는다. 해석은 각 단계에서 데이터로 확인한 사실만 쓴다.
- 단계 수나 이름을 바꿀 때는 실습 자료를 기준으로 하고, 이 문서를 먼저 고친다.

## 5. 종합 분석

상단 태그를 선택하면 해당 분석 결과를 표시한다.

- 전체 요약
- 성별 분석
- 등급 분석
- 복합 분석
- 탑승 항구 분석

기존 대시보드의 KPI, 차트, 데이터 및 분석 결과를 재사용한다.

## 6. 기존 프로젝트 활용 정책

- 기존 데이터 및 분석 코드 유지
- 실제 실습한 분석 내용만 사용
- 기존 분석 기능 재개발 금지
- 기존 대시보드의 시각 디자인은 재사용하지 않음
- 불필요한 재분석, 리팩터링, 테스트 자동화 제외
- 디자인 세부 규칙은 `design-simple.md` 참조

## 7. 작업 순서

1. 기존 프로젝트 구조 간단 확인
2. 공통 Hero 및 UI 스타일 적용
3. 랜딩 F1~F5 디자인 적용
4. 프로젝트 소개 상세 페이지 적용
5. 분석 방법 상세 페이지 적용
6. 종합 분석 상세 페이지 적용
7. 주요 화면과 버튼 동작 간단 확인

**최종 원칙:** 기존 기능을 유지하면서 새로운 디자인 스타일을 적용한다. 한 번에 하나의 화면씩 작업한다.
