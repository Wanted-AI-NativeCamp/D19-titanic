## 본문 (흰 카드)

### 01 프로젝트 배경

이 프로젝트는 데이터 분석 실습의 하나로, Kaggle에 공개된 1912년 타이타닉 승객 데이터를 사용했습니다. 승객의 성별, 나이, 객실 등급, 탑승 항구 같은 기록과 생존 여부가 함께 담겨 있어, 어떤 승객이 살아남았는지를 데이터로 확인할 수 있습니다.

### 02 분석 목적

누가 살아남았는지를 세 가지 질문으로 나누어 확인했습니다.

1. **데이터를 살펴보고 정리하다.**
   비어 있는 값을 찾고, 왜 비었는지 확인한 뒤 처리했습니다.
2. **처리 방법에 따라 결과가 달라지는지 실험하다.**
   빈 나이를 4가지 방법으로 처리해 생존율을 비교했습니다.
3. **그룹별로 생존율을 비교하다.**
   성별, 객실 등급, 탑승 항구별 생존율을 인원수와 함께 봤습니다.

### 03 데이터셋 소개

승객 한 명이 한 행이고, 칸마다 승객의 기록 하나가 들어 있습니다.

| 승객 수 | 칸 수 | 전체 생존율 |
|---|---|---|
| 891명 | 12개 | 38.4% |

| 칸 | 뜻 | 비어 있는 값 |
|---|---|---:|
| `PassengerId` | 승객 번호 (1부터 순서대로 붙인 고유 번호) | 없음 |
| `Survived` | 생존 여부 (0 = 사망, 1 = 생존) | 없음 |
| `Pclass` | 객실 등급 (1 = 1등석, 2 = 2등석, 3 = 3등석) | 없음 |
| `Name` | 승객 이름 | 없음 |
| `Sex` | 성별 (male = 남성, female = 여성) | 없음 |
| `Age` | 나이 | 177명 |
| `SibSp` | 함께 탄 형제자매/배우자 수 | 없음 |
| `Parch` | 함께 탄 부모/자녀 수 | 없음 |
| `Ticket` | 티켓 번호 | 없음 |
| `Fare` | 요금 (티켓 가격) | 없음 |
| `Cabin` | 객실 번호 | 687명 |
| `Embarked` | 탑승한 항구 (C = 셰르부르, Q = 퀸스타운, S = 사우샘프턴) | 2명 |

정제 과정에서 `age_missing`, `Title`, `has_cabin` 칸을 추가했습니다. 원본 파일은 그대로 두고 새 파일(`titanic_clean.csv`)에 저장했습니다.
