# PRD — TITANIC Ocean Archive

- **Version:** 1.3 (분석 방법 단계를 실습 8단계로 수정)
- **Project:** TITANIC — Ocean Archive
- **Type:** 기존 프로젝트 UI 리디자인
- **Design Reference:** `design.md`

## 1. 프로젝트 개요

1912년 타이타닉 승객 데이터를 분석한 실습 결과를 디지털 아카이브 형태로 제공하는 웹사이트.

**목표**
- 기존 데이터 분석 결과와 기능 유지
- 분석 과정과 결과를 쉽게 탐색할 수 있도록 구성
- 랜딩과 상세 페이지의 사용자 경험 개선

**핵심 원칙:** 새로운 분석 기능을 개발하는 것이 아니라, 기존 프로젝트에 디자인을 적용하는 작업이다.

## 2. 사이트 구조

```text
Landing Page
├── F1. Hero
├── F2. 프로젝트 소개
├── F3. 분석 방법 소개
├── F4. 종합 분석 프리뷰
└── F5. Footer

상세 페이지
├── 프로젝트 소개
├── 분석 방법 소개
└── 종합 분석
```

랜딩은 스크롤형으로 구성하고, 각 섹션에서 해당 상세 페이지로 이동할 수 있도록 한다.

## 3. 페이지별 요구사항

| 페이지 | 주요 콘텐츠 및 기능 |
|---|---|
| F1 Hero | 프로젝트 타이틀, 소개 문구, 상세 페이지 이동 CTA |
| F2 프로젝트 소개 | 프로젝트 배경·목적 요약, 상세 페이지 이동 |
| F3 분석 방법 | 실습 8단계 요약, 상세 페이지 이동 |
| F4 종합 분석 | 기존 데이터 기반 핵심 KPI·차트 미리보기, 상세 페이지 이동 |
| F5 Footer | 데이터 출처, 사용 기술, 프로젝트 정보 |
| 프로젝트 소개 상세 | 프로젝트 배경, 분석 목적, 데이터셋 소개 |
| 분석 방법 상세 | 실습 8단계 태그 선택 및 해당 실습 내용 표시 |
| 종합 분석 상세 | 분석 항목별 태그 선택 및 해당 차트·결과 표시 |

## 4. 분석 콘텐츠 구성

### 분석 방법 소개

단계별 태그를 선택하면 해당 분석 내용을 표시한다. 태그는 **실제로 실습한 8단계**를 그대로 쓴다.

`01 데이터 살펴보기` · `02 결측치 찾기` · `03 왜 비었을까` · `04 결측 처리` · `05 처리 방법 실험` · `06 그룹별 생존율` · `07 시각화` · `08 대시보드`

| 단계 | 실습 근거 |
|---|---|
| 01 데이터 살펴보기 | `t1_look.py` |
| 02 결측치 찾기 | `t2_missing.py` |
| 03 왜 비었을까 | `t2` 이후 데이터로 확인한 내용 (대응하는 스크립트 없음) |
| 04 결측 처리 | `t3_clean.py` |
| 05 처리 방법 실험 | `t4_experiment.py` |
| 06 그룹별 생존율 | `t5_groupby.py` |
| 07 시각화 | `t6_charts.py` |
| 08 대시보드 | `t7_dashboard.py` |

각 단계는 실제 실습한 내용에 따라 목적, 수행 과정, 코드, 결과 및 해석을 제공한다.

- 실습하지 않은 `인사이트 도출` 단계는 두지 않는다. 해석은 각 단계에서 데이터로 확인한 사실만 쓴다.
- 단계 수나 이름을 바꿀 때는 실습 자료를 기준으로 하고, 이 문서를 먼저 고친다.

### 종합 분석

분석 항목별 태그를 선택하면 해당 대시보드를 표시한다.

`전체 요약` · `성별 분석` · `등급 분석` · `복합 분석` · `탑승 항구 분석`

기존에 구현된 데이터, 차트 및 분석 결과를 활용한다.

## 5. 기존 프로젝트 활용 규칙

- 기존 데이터 파일, 분석 코드 및 계산 결과 유지
- 실제 실습하지 않은 분석 내용 임의 추가 금지
- 기존 대시보드의 데이터는 활용하되 디자인은 재사용하지 않음
- 기존 페이지 구조와 기능 최대한 재사용
- 불필요한 재분석, 리팩터링, 테스트 자동화 제외
- 디자인 세부 기준은 `design.md` 참조

## 6. 작업 방식

1. 기존 프로젝트 구조 간단히 확인
2. 공통 UI 및 랜딩 F1~F5 디자인 적용
3. 프로젝트 소개 상세 페이지 적용
4. 분석 방법 상세 페이지 적용
5. 종합 분석 상세 페이지 적용
6. 화면 표시와 주요 버튼 동작만 간단히 확인

**한 번에 하나의 영역씩 작업하고, 기존 기능을 유지하면서 디자인 적용에 집중한다.**
